Operationalisation: make an idea observable

Move from a theoretical claim to a comparison and a measurable response.
1. What is the idea? Word-order knowledge helps people remember a sequence.
2. What would differ? Recall of different word orders, using the same kind of material.
3. What can we record? Whether the studied order is reconstructed correctly on each trial.
What pattern would support the idea, and what else could produce that pattern? Order accuracy measures memory performance; word familiarity or task difficulty could affect it too.

Example 1: word-order memory task

Can people with substantial Qur’anic Arabic experience, but little spoken Arabic, use word-order knowledge to remember short word sequences?

Why ask?

Repeated reading or recitation may support knowledge of structure beyond simply recognising individual words.

If order knowledge supports memory, some orders should be recalled more accurately than others.

What is compared?

Language: English and Arabic.

Order: SVO, VSO, and SOV.

Measure: proportion of trials with the studied order correctly reconstructed.

S = subject; V = verb; O = object.

Example 1: study, distractor, recall

Keep the sequence constant; change the language and word order across trials.

Example 1: why is each stage there?

Study the words Give participants a sequence whose order they must remember.
Judge the equation Interrupt rehearsal before recall; the main outcome is order reconstruction.
Rebuild the order Supply the words again so the response mainly records order accuracy, rather than spelling or word retrieval.
What would change if recall followed study immediately? The equation is an intervening task, not the outcome.

Example 2: spelling and word order

Does the spelling difficulty of an object’s name change which object writers mention first in a sentence?

Why ask?

Writers may consider object names while choosing how to begin a sentence.

If one name is difficult to spell, they may be less likely to put that object first.

How could we test it?

Task: write a sentence describing two pictures.

Vary: spelling diversity; prompt spelling: correct, plausible, or incorrect.

Measure: whether the target object is mentioned first.

Spelling prompt for “piranha”: correct piranha · plausible pirahna · incorrect prianha.

Example 2: why are these screens there?

Picture + spoken name Establish the intended object name without displaying its spelling.
Spelling decision Show one spelling and ask whether the participant would normally write it that way. This records whether the displayed form matches their own preference.
Typed description Record which pictured object the writer mentions first.
For each stage: what uncertainty does it address, and how might it change the behaviour we measure?

Counterbalance picture position; a left-to-right description preference could otherwise affect first mention. Picture-naming norms are a separate materials check.

What else could change the response?

  • Equation trials: include correct and incorrect answers; balance them across the main conditions. Equation difficulty could affect later recall.
  • Spelling prompts: balance the three forms and record each participant’s judgment; a researcher-labelled “correct” form may not be their usual spelling.
  • Screen position: vary or counterbalance where pictures appear. A fixed position could determine which object is mentioned first.
  • Trial number and order: plan enough trials per condition and distribute them across the task. Repetition and fatigue may change later responses.
  • Display duration: decide how long primes, prompts and targets appear, and keep timing comparable across conditions.
  • Fixation crosses: decide whether they help start each stage from a common point; specify when and for how long they appear.
For every stage: what does it contribute, what else might it change, and how will you keep it comparable?

Define the population before recruiting

Knowing participants does not replace recording who they are as a sample.
Define eligibility State the age range, language experience and task skills.
Ask everyone Use the same background questions, even when you know participants personally.
Report the sample Describe the relevant characteristics.
A study needs a documented eligibility rule and recorded participant background so others can interpret its findings.

For example, two French–English speakers may differ in when they learned each language, current use, literacy and skill.

Who? Possible age range, languages and where you could find participants.
Which skills? For each relevant language, consider listening and speaking, plus reading and writing or script literacy.

Why does it matter? Which characteristics are needed for your task, or could affect the result?
List the background information you need from every participant. Then find a language-background questionnaire that records it; add justified study-specific questions if needed.

What do background checks record?

Learning history Which languages, age of first exposure, and where and how each was learned.
Current use How often each language is used now, with whom, and for speaking, reading or writing.
Relevant skill Listening, speaking, reading and writing separately; add a task-matched performance check if needed.
Task experience For example, script literacy, target-word familiarity, accent exposure or typing in each language.
For the word-order task: Qur’anic reading and recitation, spoken Arabic use, script literacy and word familiarity are different things to record.

Choose only relevant questions, ask everyone the same ones, and specify eligibility before recruiting.

Match background checks to the question

Language profile LEAP-Q or LHQ3: learning history, exposure, current use and self-rated skills.
Use and dominance LSBQ: use across social contexts. BLP: a relative self-reported dominance profile.
Observed performance LexTALE/LexTALE-FR: written-word knowledge. MINT: picture-naming accuracy.
Switching habits BSWQ: reported everyday switching tendencies; it does not measure experimental switch costs.

Choose a short, justified set. A score on one test is not general proficiency. Participant background guide: Teams → Session 3.
